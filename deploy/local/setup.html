إعداد هذا الجهاز لنظام المطعم

خطوة واحدة لكل جهاز (جوال، تابلت، كمبيوتر): تثبيت شهادة الأمان الخاصة بالمطعم، حتى يعمل النظام بأمان ويتحمّل انقطاع الشبكة ويمكن تثبيته كتطبيق.

جارٍ فحص الاتصال الآمن…

1) تنزيل شهادة المطعم 2) فتح النظام

📱 أندرويد
  1. نزّل الشهادة من الزر أعلاه.
  2. الإعدادات ← الأمان والخصوصية ← إعدادات أمان أخرى ← تثبيت من وحدة التخزين ← شهادة CA.
  3. اختر الملف RMS-Local-CA.crt وأكّد التثبيت.
  4. افتح النظام في Chrome، ثم من القائمة ⋮ اختر تثبيت التطبيق.
🍎 iPhone / iPad
  1. افتح هذه الصفحة في Safari ونزّل الشهادة، ثم اختر "سماح".
  2. الإعدادات ← تم تنزيل الملف الشخصي ← تثبيت.
  3. الإعدادات ← عام ← حول ← إعدادات الثقة بالشهادات ← فعّل الثقة الكاملة لـ "Caddy Local Authority".
  4. افتح النظام في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
🪟 ويندوز
  1. نزّل الشهادة وافتحها ← تثبيت الشهادة ← الجهاز المحلي (Local Machine).
  2. اختر "وضع كل الشهادات في المخزن التالي" ← المراجع المصدقة الجذر الموثوقة ← إنهاء.
  3. أعد تشغيل المتصفح وافتح النظام، ثم زر تثبيت في شريط العنوان.
💻 ماك
  1. نزّل الشهادة وافتحها لتُضاف إلى Keychain Access (سلسلة المفاتيح: System).
  2. انقر عليها مرتين ← الثقة ← الثقة دائمًا.

الشهادة خاصة بخادم هذا المطعم فقط، ولا تعمل إلا على شبكته. لا تثبّت شهادات من مصادر لا تعرفها.
